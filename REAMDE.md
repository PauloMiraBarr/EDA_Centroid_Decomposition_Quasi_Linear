# Centroid Decomposition en tiempo O(n log log n)

Resumen semana 1:

Centroid decomposition algoritmo clásico implementado.
Asunciones importantes:
 - Es un árbol, pero por comidad le llamaré grafo.
 - Se asume que el grafo funciona en base a números, o sea, indexación numérica.
 - Se asume que el grafo está indexado en 1.
 - El 0 actúa como un super padre (o super contenedor de todo el grafo).
 - ¿Ya fueron las elecciones?

Para ejecutar debe tener una temrinal compatbile con *bash*.
```bash
bash build.sh
```
Creará una carpeta llamada *build* donde estará el ejecutable.
